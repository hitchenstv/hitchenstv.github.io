# Where to Find Things

## Servers and game versions

Titan Reforged runs on NetEase's "Time" realm cluster. The main PvE realm discussed in our community is Titan Reforged, the "Time" (时光) server, with additional realms 时光II through 时光VI. Servers can get renamed by the top PvP guilds (they win naming rights), which is why your WTF folder sometimes breaks after a phase changes. Use the WCLBox Server Data Migration tool to fix it.

One subscription covers all CN versions. Titan Reforged (the "Time" server), plus retail, MoP, anniversary, and hardcore, all expansions.

## Tools to install

GearUP Booster is latency fix, YY voice routing, and automatic English client locale switch. Basically required overseas. Read about it here: [gearupbooster.com](https://www.gearupbooster.com/)

NewBeeBox is addon manager, WoWSimsCN, server migration, and cloud backups. Find it here: [wclbox.com](https://www.wclbox.com/)

TranslateCN is Chinese chat to English. Find it here: [CurseForge: TranslateCN](https://www.curseforge.com/wow/addons/translatecn)
